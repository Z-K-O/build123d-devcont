# CAD

This directory is where design files created inside the dev container live by default. Files placed here aren't tracked by git — the container's scratch space is meant for active work, not version history.

You're not limited to working here, though. The project folder is bind-mounted from the host, so design files stored elsewhere on your local machine are just as usable from inside the container — open, edit, and save them normally, wherever they happen to live.
